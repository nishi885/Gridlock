Approach:

The objective of this project was to develop an accurate machine learning model for predicting traffic demand using structured data containing spatial, temporal, and road infrastructure features. The overall approach followed an end-to-end supervised learning pipeline, starting from data preprocessing and feature engineering to model training, evaluation, and final prediction.

To ensure robust performance, multiple Gradient Boosting algorithms were explored and compared under a consistent validation framework.

1. Model Selection Strategy

The given dataset contains non-linear relationships between features such as geohash, time, and road structure, so tree-based models were selected as the primary modeling approach.

These models were chosen because they are highly effective for tabular datasets and are capable of capturing complex feature interactions without requiring extensive data scaling or transformation.

The models explored include:

XGBoost Regressor
LightGBM Regressor
CatBoost Regressor

Each model was trained independently using the same dataset split to ensure fair comparison.

2. Individual Model Development

XGBoost Model

XGBoost was configured with 1500 estimators, a learning rate of 0.03, random sample of 42 and a maximum depth of 8. This model was designed to capture deep and complex patterns in the dataset.

It performed exceptionally well in learning non-linear relationships between spatial and temporal variables. Due to its strong regularization mechanism and efficient gradient boosting framework, it achieved the highest validation performance among all models.

LightGBM Model

LightGBM was trained with 1000 estimators, learning rate of 0.05, max depth of 8, and 100 leaves.

This model was selected for its computational efficiency and ability to handle large datasets. While it trained significantly faster than XGBoost, it showed slightly lower predictive performance.

CatBoost Model

CatBoost was configured with 1000 iterations, learning rate of 0.03, and depth of 10.

It is particularly used for its ability to handle categorical variables natively, reducing preprocessing requirements. However, in this dataset, its performance was comparatively lower, likely because engineered numerical and spatial features had higher predictive importance than raw categorical inputs.

3. Model Comparison and Selection

All models were evaluated using R² score on the validation set under a consistent evaluation strategy.

The results were:

XGBoost: 0.95
LightGBM: 0.94
CatBoost: 0.75

Based on these results, XGBoost demonstrated the best balance between accuracy and generalization ability. It consistently captured complex relationships in the data more effectively than the other models.

4. Feature Importance

After model training, feature importance analysis was conducted to understand the key drivers of traffic demand.

The most influential features were:

road_type_enc             
large_vehicles_allowed   
geohash_target_enc        
vehicle_per_lane          
hour_sin                 
hour_cos                 
weekday                   
geo_std                  
is_peak_hour             
is_weekend   

This analysis revealed that traffic demand is primarily influenced by a combination of road infrastructure, geographic location, and temporal patterns, while external factors like weather and landmarks had relatively lower impact.

5. Final Pipeline Workflow

The complete machine learning pipeline followed in this project is illustrated below:

Raw Data 
Data Cleaning 
Missing Value Handling 
Feature Engineering 
Encoding 
Train-Validation Split 
Model Training (XGBoost / LightGBM / CatBoost) 
Evaluation using R² Score 
Best Model Selection 
Final Prediction Generation

This structured pipeline ensured reproducibility, consistency, and reliable performance evaluation across all models.

6. Final Outcome

The XGBoost model was selected as the final model due to its superior performance, achieving a validation R² score of 0.95. This model demonstrated strong generalization ability and was able to effectively capture both spatial and temporal dependencies in traffic demand data.

The overall approach focused on:

Systematic preprocessing and feature engineering
Comparative evaluation of multiple gradient boosting models
Careful validation using R² score
Selection of the best-performing model based on generalization performance

This methodology ensured a robust and data-driven model selection process for traffic demand prediction.
